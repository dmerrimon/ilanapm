## Implementation Details

### Code Changes

**File**: `backend/services/template_generator.py`

**New Method**: `_sort_tasks_by_workflow(tasks, category)`
- Defines priority ordering for each category
- Sorts tasks by workflow sequence (1-99 priority)
- Filters duplicate entries
- Returns organized task list

**Priority Examples**:

**Data Management**:
- Priority 1: Data Collection Forms First Draft
- Priority 2: Data Collection Forms Development (final)
- Priority 8: Data System Configuration
- Priority 10: Database Deployed
- Priority 15: Data System Opens for Enrollment
- Priority 23: Statistical Analysis

**Study Closeout**:
- Priority 1: Clinical Data Entry
- Priority 2: Data Cleaning
- Priority 6: Clinical Database Lock
- Priority 10: Laboratory Database Lock
- Priority 12: Preparation of Draft CSR
- Priority 23: Final CSR Submission

### Duplicate Removal

**Before**: 27 Study Closeout tasks (with 1 duplicate "Laboratory Database Lock")
**After**: 26 Study Closeout tasks (no duplicates)

**Implementation**:
```python
# Filter out duplicate entries
if category == 'Closeout':
    filtered_tasks = []
    seen_names = set()
    for task in sorted_tasks:
        task_name_lower = task.name.lower()
        # Skip exact duplicates (keep first occurrence only)
        if task_name_lower in seen_names:
            continue
        seen_names.add(task_name_lower)
        filtered_tasks.append(task)
    return filtered_tasks
```
